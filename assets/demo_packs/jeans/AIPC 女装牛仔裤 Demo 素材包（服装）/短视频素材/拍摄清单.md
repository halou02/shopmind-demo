# 竖屏短视频拍摄清单

每条 3 至 5 秒，使用手机 9:16 竖屏拍摄。若拍到真人，请征得本人同意，仅将内容用于比赛演示。

1. 平铺整理：从腰头到裤脚缓慢扫过，展示中靛蓝和直筒线条。
2. 试穿拉链：只拍腰部与手部，展示高腰位置、纽扣和前袋细节。
3. 坐下再起身：从侧后方拍摄坐到椅子上再起身，展示久坐和起身的自然活动感。
4. 三步走路：镜头固定，人物从左至右走三步，展示裤脚和直筒线条。
5. 下班咖啡馆：人物坐在咖啡馆轻微调整坐姿，最后给裤脚与鞋的特写。

如果没有真人模特：用衣架拍平铺、腰头和裤脚，外加 Pexels 或 Mixkit 的办公室或咖啡馆空镜做一秒转场。不要把库存视频中的牛仔裤当作本商品上身素材。
