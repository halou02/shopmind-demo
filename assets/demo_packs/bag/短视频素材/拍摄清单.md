# 竖屏短视频拍摄清单

每条 3 至 5 秒，使用手机 9:16 竖屏拍摄。不要开美颜或使用复杂转场；稳定、清楚即可。

1. 空包拎起：在白墙或办公桌前，一只手从桌面拎起包，展示轻盈感。
2. 装包过程：依次放入 13 英寸电脑、水杯、笔记本、耳机和折叠伞，最后拉上拉链。
3. 前口袋特写：取放地铁卡或手机，展示随手可拿。
4. 肩背出门：从后方或侧后方拍摄走出办公楼，包完整入镜。
5. 下班咖啡馆：包放在椅子上，镜头由咖啡杯缓慢移到包。

若无法实拍：只将 Pexels 或 Mixkit 的“办公楼外走路”“咖啡馆桌面”等素材用作 1 秒环境转场，不要把库存视频中的陌生包冒充本商品。产品主体仍用本文件夹中的图像、屏幕录制或自己的实拍完成。
