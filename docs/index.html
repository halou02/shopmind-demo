Why ShopMind

不拍脑袋，让每一句文案都有出处

把「品牌 + 商品 + 评价 + 图片」当作唯一事实来源，输出可回溯、可审阅、可交付的创意内容。

🔗

证据可溯源

每个创意方向都绑定 evidence（评价洞察）与 asset（图片素材），标出「基于哪条评价、哪张图」，避免空泛套话。

Creative Pipeline

创意五步 · 从资料到可交付内容包

全过程可视化、可回溯：每一步都有明确输入输出，随时能停下检查 AI 的理解是否正确。

STEP 01

录入

上传商品资料 / 图片，或从素材库选取，支持 Excel、文档、图片等多种格式。

app/web/materials_flow.py
STEP 02

理解

扫描来源、抽取证据，生成商品理解卡与经营判断，并可由你手动修正。

app/core/product_understanding.py
STEP 03

方向

基于理解结果生成多个带证据的创意方向供选择，每个方向都标注推荐素材与禁忌表达。

app/core/creative_directions.py
STEP 04

生成

产出多平台文案、20 秒视频脚本、视觉提示词与配图，文生图 / 文生视频可按需触发。

app/core/content_generator.py
STEP 05

导出

打包为标准内容包（manifest + contentpackage + content/*.md），附 SHA256 校验便于审阅集成。

app/export/content_package.py

方向 A · 早八不慌的一包秩序

目标人群：讨厌负担感、重视穿搭比例的城市女性。 核心洞察：用户不想背一个功能多却显笨重的包；轻量既是身体负担，也是一种从容感。 核心表达：装下工作，也不把肩膀交给负担。 绑定证据：评价高频提及「轻」「不压肩」；商品参数约 380 g。 推荐素材：03 通勤场景图、视频 1 空包拎起、视频 4 肩背出门。 不建议重复：不使用「显瘦神器」「一秒显瘦」等夸张说法。
Under The Hood

技术栈

后端

Python 3.11+ · FastAPI · Uvicorn，71 个路由，模块化拆分理解 / 判断 / 方向 / 生成 / 导出。

前端

原生 HTML / CSS / JS，零构建、零依赖，双击 .bat 即可启动。

AI 能力

OpenAI 兼容接口（默认阿里云百炼 Qwen 系列），文本 / 视觉 / 图片 / 视频分别可配，也支持本地 Ollama。

质量保障

pytest 40+ 用例；导出带 manifest 与 SHA256 校验，内容包结构化、可审阅。

Run Locally

本地运行，两步启动

ShopMind 是完整可运行的应用。GitHub Pages 只承载本展示页；要体验完整功能，请在 Windows 上本地运行。

Windows 快速开始

  1. 双击 首次安装.bat：检测 Python 3.11+、创建 .venv、安装依赖。
  2. 双击 启动网站.bat：启动服务并自动打开浏览器。
  3. 访问 http://127.0.0.1:8080 开始创作。
⚙️ 配置 AI（可选）：在项目根 .env 或网页右上角「AI 设置」中填入百炼 API Key。未配置 Key 时，仍可基于本地资料生成离线演示内容包。

从源码运行

# 1. 克隆仓库
git clone https://github.com/halou02/shopmind-demo.git
cd shopmind-demo

# 2. 创建环境并安装依赖
python -m venv .venv
.venv\Scripts\activate
pip install -e .

# 3. 启动
python -m app.web_main
# → http://127.0.0.1:8080

也可安装开发依赖后运行测试：pip install -e ".[dev]" 然后 pytest。
