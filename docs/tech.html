05 / TECHNOLOGY

本机跑完，云端只是可选。

ShopMind 是本地优先的 AIPC 应用：资料、索引、历史与导出包留在本机；文本与视觉能力可以分别选择云端或端侧，配置项随时可替换。

Python 3.10+ FastAPI Local-first

Layered Architecture

四层，
每层只做一件事。

前端保持零构建，接口层只负责编排，核心层把理解与生成拆成可测试的步骤，持久层把每个产物落成可审阅的文件。

01 / UI

交互层

127.0.0.1:8080零构建

原生 HTML / CSS / JavaScript，11+ 业务界面。素材录入、五步流水线、商品库、理解卡、内容生成与导出都在同一套本地工作台里完成。

02 / API

接口层

FastAPIUvicorn

REST 接口承载上传、分析、发布、AI 设置、品牌记忆与历史查询。接口层不写业务规则，只负责把工作区上下文交给流水线。

03 / CORE

核心层

StepsPipeline

来源扫描、证据抽取、商品理解、经营判断、创意方向、内容生成、内容包导出。分析链与发布链分离，每一步独立校验、独立失败。

04 / DATA

持久层

workspace/SHA256

上传、素材库、商品目录、任务历史与导出包都落在本地文件系统。结构化 JSON 与 Markdown 并存，可直接审阅或接入外部工具。

Run Locally

两步启动，
或者从源码开始。

GitHub Pages 只承载这个静态展示站。要体验完整流水线，请在 Windows 本地运行；需要 Python 3.10+。

Windows 快速开始

双击两个 .bat，不需要命令行

  1. 双击 首次安装.bat：检测 Python 3.10+、创建 .venv、安装依赖。
  2. 双击 启动网站.bat：启动服务并自动打开浏览器。
  3. 访问 http://127.0.0.1:8080 开始创作。
AI 配置 Key 是可选项。未配置时，仍可基于本地资料走完五步，生成离线演示内容包。

从源码运行

Python 3.10+ · Windows / macOS / Linux

# 1. 克隆仓库
git clone https://github.com/halou02/shopmind-demo.git
cd shopmind-demo

# 2. 创建环境并安装依赖
python -m venv .venv
.venv\Scripts\activate
pip install -e .

# 3. 启动
python -m app.web_main
# → http://127.0.0.1:8080

开发依赖可运行 pip install -e ".[dev]"，随后执行 pytest。Linux / macOS 将激活命令替换为 source .venv/bin/activate。

CONTRACTS

7 个固定产物

每类产物都有结构契约与导出校验，清单逐文件生成 SHA256，避免「看起来导出了」。

BOUNDARY

边界写进产物

理解卡与导出包都带 boundary_notice：「仅基于本地资料」，不把演示数据当成经营结论。

仅基于本地资料

内容来自用户提供的商品资料、评价与图片；不编造评价，不做外部市场推断。

未接入市场 / 利润 / 竞品

不对市场规模、利润空间与实时竞品作判断；需要这些结论时应另行补充数据。

演示数据为虚构

品牌、参数、评价与历史内容均为比赛演示数据，不代表真实用户反馈或经营表现。
